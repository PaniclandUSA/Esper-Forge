# ESPER-FORGE Documentation

This directory contains the **formal, normative documentation** for ESPER-FORGE.

These documents define what the system *is*, what it *refuses to do*, and the
mathematical and ethical constraints under which it may operate.

This is not marketing material.
It is not a tutorial-first guide.
It is the **specification space** of the Forge.

If something is ambiguous here, it is ambiguous in the system itself.

---

## How to Read These Documents

ESPER-FORGE is built deliberately, in layers.
Each document assumes the constraints established by the ones before it.

**Do not skip ahead unless you already understand the geometry.**

Recommended order:

1. **00-OVERVIEW.md**  
   What ESPER-FORGE is, why it exists, and what problem it is *actually* solving.  
   This document establishes scope, non-goals, and epistemic posture.

2. **01-DIGNITY-MANIFOLD.md**  
   Defines dignity as a geometric invariant rather than a moral aspiration.  
   This is a *normative* document. Everything else depends on it.

3. **02-COLLAPSE-CRITERION.md** *(in progress)*  
   Specifies when uncertainty may be collapsed—and when it must not be.  
   Establishes the human-only boundary for judgment and consequence.

4. **03-ENTANGLEMENT-OPERATORS.md**  
   Formal mathematical operators for treating truth as correlation structure.  
   This is the core technical bridge between philosophy and verification.

5. **04-ARCHITECTURE.md**  
   The complete system architecture: data flow, operator interaction,
   validation stages, and certification boundaries.

6. **05-LITERACY-DEMO.md**  
   Application of ESPER-FORGE to dignity-preserving literacy transformation.  
   Demonstrates conservation of meaning across reading levels.

7. **06-JOURNALISM-DEMO.md**  
   WitnessJournalist use case: certifying measurement integrity without
   collapsing contested truth prematurely.

8. **07-LEGAL-STANDARD.md**  
   How ESPER-FORGE certificates can function as admissible evidence artifacts
   without substituting algorithmic judgment for human authority.

9. **08-DEPLOYMENT.md**  
   Practical guidance for integrating ESPER-FORGE as a verification layer
   around existing AI systems.

## Normative vs. Exploratory Documents

Some documents define **hard constraints**.
Others explore **applications** of those constraints.

- **Normative (binding):**
  - 00-OVERVIEW.md
  - 01-DIGNITY-MANIFOLD.md
  - 02-COLLAPSE-CRITERION.md
  - 03-ENTANGLEMENT-OPERATORS.md
  - 04-ARCHITECTURE.md

- **Applied (illustrative, not binding):**
  - 05-LITERACY-DEMO.md
  - 06-JOURNALISM-DEMO.md
  - 07-LEGAL-STANDARD.md

Applications may evolve.
Normative constraints do not—except through explicit, reviewed revision.

## A Note on Language

You will see language here that is:

- geometric rather than probabilistic
- conservative rather than optimistic
- precise rather than friendly

This is intentional.

ESPER-FORGE treats:
- meaning as conserved quantity
- ethics as boundary condition
- truth as entangled structure
- judgment as human responsibility

If a statement feels restrained, it is.
If something is not claimed, it is because it cannot be proven.
